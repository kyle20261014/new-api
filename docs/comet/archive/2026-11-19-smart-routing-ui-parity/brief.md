# 目标

将现有智能路由的界面、交互与提示完整对齐参考站 https://ai.lk888.ai/api/console/keys 的路由配置体验；不是只更换配色或圆角。保留用户明确要求的“路由模式：智能路由 / 固定分组”，在其下提供完整策略区、帮助弹层、动态排除工作台、自定义两步流程与真实候选指标。帮助采用用户看图后明确指定的弹层方式。

原始请求：用户允许 1:1 复刻，要求充分浏览学习后实现，指出现有基本功能已有而样式、交互与提示过简。后续明确：路由模式由用户提出，保留。参考页面已登录并允许直接通过 Chrome 阅读。本轮在参考站只操作未提交的新 Key 草稿，不创建真实 Key，不调用付费模型。

# Scope

范围限定为用户提供的三张截图及其必要交互，以及后续看图修订：渠道策略下拉与选中说明、“怎么选”帮助弹层、动态渠道管理、自定义模型/分组选择和调度配置。参考站同页的名称、额度、IP 白名单、站点导航和账号资料不在复刻范围；魔丸已有这些功能保持原行为。
