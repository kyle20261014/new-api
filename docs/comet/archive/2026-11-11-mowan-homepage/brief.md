# Outcome

将本项目默认首页改为魔丸AI品牌的创作平台展示首页，完整复刻参考 https://ai.lk888.ai/zh-CN 首页的分节结构、视觉层级、黑底星空、蓝青光效及滚动交互。采用用户选定的 A 赤焰魔丸 Logo；模型、作品使用示例内容，未实现功能保留占位链接。通过 Comet Native 完成实现、检查和独立验收。

# Scope

范围是参考站首页从页头到页脚的全部可见分节，以及其桌面和移动端布局、导航、悬停、滚动、装饰动画。只把首页作为需求来源，导航指向的后台、创作工具、定价等内页不属于复刻范围。参考站登录用户的姓名、头像、余额和其他个人信息不复制。最终以本地原生 React 页面交付，保持项目现有 `/` 路由和七语言机制。

## 目录结构

### 新建

- `web/src/features/home/components/mowan-landing/` — 首页专属页头、分节、页脚、示例数据、动效和作用域样式，避免影响其他页面。
- `web/public/images/mowan/` — A 方案的生产 Logo 和首页示例作品素材。
- `web/src/features/home/__tests__/` — 集中验证自定义首页兼容、导航和关键交互的回归用例，优先沿用已有合适测试。

### 修改

- `web/src/features/home/index.tsx` — 仅替换默认分支，保留加载态、自定义 URL iframe、HTML、Markdown 分支。
- `web/src/i18n/locales/{en,zh,zh-TW,fr,ru,ja,vi}.json` — 补齐首页新增用户文案，复用既有英文键。
- `web/src/components/layout/` — 仅当既有 PublicLayout 缺少能力时添加兼容的首页页头开关；其他页面保持原行为。
- `web/package.json`、`web/bun.lock` — 登记并锁定用户已批准的Three.js及必要类型声明依赖，用于首页粒子与光晕。

### 明确不建

- 不新增后端接口、数据表、鉴权、支付、创作引擎或模型查询服务；不改计费和数据库。
- 不新增语言前缀路由、不手改生成的路由树、不新建通用落地页框架。
- 不修改全局品牌配置或其他页面外观；B、C 备用 Logo 保留在已提交的品牌素材目录。

# Non-goals

不接入参考站接口或账户，不实现对话、图像/视频/语音生成、充值或支付，不宣称示例模型已接入。不会把参考站的手机号、二维码、用户资料、Logo 或第三方品牌归属替换成本项目事实。不推送代码或发布生产站点。

# Acceptance examples

1. A1：默认首页首屏呈现魔丸AI与A赤焰魔丸Logo，保留参考站近黑星空、蓝青主视觉、大标题、模型漂浮元素、粒子环和固定页头的构图关系，Logo在桌面与手机均清晰；B/C备用稿保留。
2. A2：创作分节保留参考布局、文案层级、输入框式入口和对话/图片/视频/语音类别，点击不发起真实生成请求。
3. A3：模型分节以示例模型呈现对应Logo/名称、排布密度、背景层次和动效，不依赖用户权限或真实模型接口。
4. A4：声音分节保留原有文案、语音合成/音乐生成两类胶囊及描边CTA；粒子与内容的对应沿用用户2026-11-11上午亲测确认的原始连续进度，不强制将声音区映射到涡旋终态。不新增播放、录音或上传；前端效果由用户验证。
5. A5：灵感作品以本地示例图片呈现参考瀑布流及悬停层次，页脚包含对应信息分组和品牌收尾，悬浮入口可见；素材加载稳定，不抄入他人的个人联系方式。
6. A6：页头、分节导航点、主CTA及作品/功能入口具有一致的活动态、悬停/聚焦和点击行为；分节定位可用，已有登录/注册/控制台沿用本地路由，未实现的创作功能保留安全占位链接且不跳到参考站。
7. A7：在1920、1440、768、390和375像素宽度下，分节、导航及作品均无横向溢出或遮挡；支持键盘焦点、可读文本与足够对比，减少动态效果偏好关闭非必要持续运动，手机不依赖悬停完成操作。
8. A8：自定义URL、HTML和Markdown首页及加载态保持原行为；新增用户文案覆盖七种语言，首页深色视觉不修改全站主题；类型、lint、格式、相关回归测试与生产构建均有真实检查结果，独立只读Verifier仅核对代码与命令证据，前端视觉和交互由用户亲自验收。代理停止自动浏览器操作，不根据截图自行改动效果，未获用户结果时不声称视觉通过。

# Constraints and invariants

复用现有Button、导航、品牌图标、翻译和动画能力；修改UI前加载shadcn-ui并查看现有组件及调用。用户于2026-11-11明确允许本首页粒子/WebGL及光晕使用Three.js（three@0.185.0、官方addons及必要的@types/three类型声明和传递依赖），对应更新web/package.json与web/bun.lock并保留MIT声明；不新增其他无关依赖。原始Logo是展示板，Build中提炼适用于页头和小尺寸的图标/字标，不能直接将整张展示板当Logo。动画优先CSS及已有motion，装饰层不可阻挡点击；非首屏图片懒加载，避免手机粒子动画过度占用资源。示例媒体素材在项目内保存，避免热链失效。

开发在 `feat/mowan-homepage` 与独立worktree执行；baseline为 `b9397cca5`。这里只涉及前端，不要求三数据库迁移矩阵；不把文档检查当作运行时验证。

# Decisions

用户已确认：只复刻整个首页；品牌为魔丸AI；使用A赤焰魔丸Logo、B/C留备用；保留参考黑底星空蓝青色；模型和作品用示例；暂缺功能用占位链接；按Comet执行并使用独立worktree。不开另一个需求或改走其他workflow。

# Verification expectations

Build后在web工作目录执行 `bun run typecheck`、`bun run lint`、`bun run format:check`、`bun run test`、`bun run build`，必要时先用vfox准备仓库指定版本。实际失败逐项记录并在Build修复；不以静态检查替代浏览器验收。按用户2026-11-11明确指令「前端验证交给我」，代理不再启动浏览器、截图比对或自行据图调整效果；这些视觉及交互验收由用户负责。Runtime与独立只读Verifier仅检查源码、类型、回归测试、格式及构建证据，区分用户已亲测事实与仍待用户验证的内容；不把命令通过冒充用户前端验收。
