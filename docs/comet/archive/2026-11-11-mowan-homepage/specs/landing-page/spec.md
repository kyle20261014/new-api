# 魔丸AI展示首页

## 能力与边界

本能力替换项目 `/` 路由的默认首页，以魔丸AI品牌呈现 https://ai.lk888.ai/zh-CN 首页的完整分节体验。以真实浏览得到的桌面和移动端画面作视觉基准，保持黑色星空、蓝青光效及信息层级；参考方标识改为用户选定的A赤焰魔丸Logo。示例模型和作品用于前端展示，未实现的创作功能保留占位链接，不产生后端调用。

参考首页的登录后个人信息不属于展示内容；沿用本项目会话，登录/注册/控制台使用已有本地路由。管理员配置自定义首页时，继续使用原有URL、HTML或Markdown内容。仅默认首页拥有定制样式，其他页面与全站主题不受影响。

## 首屏

固定页头包含魔丸AI图标与字标、模型/创作/灵感/API等入口及本地账号入口。桌面保持居中内容区域和两列构图：左侧眉题、两行大标题、副文案与CTA，右侧星尘球体/粒子环/轨道及漂浮模型胶囊。主按钮使用蓝青强调、背景近黑且带星点，右侧有分节导航，底部提供向下探索提示。首页整体保持参考站的留白、字体尺度关系及明暗层次，不改成普通功能卡片拼接页。

Logo生产素材须提炼A方案的红色球形火焰旋涡及魔丸AI字标，在深色背景、手机页头与较小尺寸可辨识。B、C方案保留为备用，不随机替换。粒子/WebGL及光晕允许使用用户于2026-11-11明确批准的three@0.185.0、官方addons及必要的@types/three类型声明和传递依赖，并保留MIT声明；其余漂浮与界面动效复用CSS或现有motion，不新增无关依赖。
