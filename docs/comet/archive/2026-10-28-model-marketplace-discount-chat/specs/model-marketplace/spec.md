# 模型广场折扣与对话入口

## 折扣

卡片和列表依据当前分组筛选计算折扣。所有分组时，从模型启用分组与访问者可用分组的交集中取最低有效倍率；选定分组时，只取该组倍率，该组必须可用且模型启用。有限、非负数字才是有效倍率，不从其他模型、无权限分组取值；指定组无有效倍率时不回退到其他组。折扣不受充值展示开关、货币或汇率影响。折数为倍率乘10，使用项目格式化能力避免浮点尾差、不必要尾零及边界舍入失真。

### Scenario: 最低与选定分组倍率

Acceptance: A1

WHEN 模型可用倍率为0.3、0.5、1且选择所有分组，THEN 显示“低至3折”；WHEN 选择0.5组，THEN 显示“5折”；切回所有分组恢复“低至3折”。卡片与列表一致。账号不可用分组不参与计算。

### Scenario: 免费及无折扣边界

Acceptance: A2

WHEN 当前展示倍率为0，THEN 显示“免费”；WHEN 在0与1之间，THEN 所有分组显示“低至x折”、指定分组显示“x折”；WHEN >=1或无有效倍率，THEN 隐藏折扣。缺失、负数、NaN及无穷值不得产生免费或虚假折扣；0.0001对应0.001折、0.9999对应9.999折，不显示0折或10折。

## 对话入口

仅为现有游乐场支持的对话模型提供入口，不将仅支持图片、视频、嵌入等非对话模型送入文本对话，也不误排除可对话的多模态模型。卡片右上角交换现有对话和复制位置，视觉顺序为复制在前、对话在后；列表相邻操作保持一致。原有详情与复制行为保留。使用本站路由传递并校验模型名称，不扩展登录协议或接受外部跳转。

### Scenario: 进入目标模型

Acceptance: A3

WHEN 点击对话入口，THEN 进入游乐场并选中目标模型，不自动发送、不清空聊天。详情继续打开详情，复制继续复制模型名；两个图标位置交换且各自可访问名称正确。非对话模型不显示对话入口。

### Scenario: 分组选择与不可用状态

Acceptance: A4

WHEN 目标模型与分组选项加载完成，THEN 若游乐场当前分组对账号可用且支持模型则沿用，否则选择账号可用且支持目标模型的最低倍率组；相同倍率按现有选项顺序稳定选择。模型广场筛选组不额外改变此预选规则。异步默认选择不能覆盖指定目标。WHEN 可用分组为空、模型不可用或加载失败，THEN 明确提示，保留原配置和聊天；后续选项刷新也不能静默改选另一模型冒充成功。

## 访客

复用现有公开定价和登录回跳。访客使用公开可用分组，登录用户使用账号可用组与实际倍率；身份变化后重新取得定价，避免复用访客或其他账号缓存。

### Scenario: 访客查看与登录后返回

Acceptance: A5

WHEN 站点允许公开查看且未登录，THEN 依所有分组/指定分组规则展示公开折扣，入口提示“登录后体验”，经现有认证路由登录并保留目标模型。WHEN 登录成功，THEN 返回目标模型，重新检查账号权限及分组并刷新价格；目标不可用明确提示。原要求登录查看模型广场的设置保持有效。

## 可访问性与国际化

### Scenario: 醒目标签、多语言与窄屏操作

Acceptance: A6

卡片折扣为醒目的独立标签，仅参考用户第二张截图的独立描边、小标题及较大折数字号层次，不固定金色。使用当前主题语义色：亮色主题使用浅色底与清晰描边，暗色主题使用低亮度底色，折数与强调色契合当前主题主色，保证文字对比度；切换主题实时更新。前端在现有设计系统内确定具体尺寸和布局。列表使用一致且紧凑的折扣样式。不增加无数据依据的官方价、划线价或节省金额。

WHEN 切换任一支持语言，THEN 折扣和入口使用准确对应翻译及合法数字语言参数，中文3折等价于减价70%；所有分组与指定分组的“最低/确切”含义也保持一致。图标有可访问名称并可键盘操作。窄屏仍完整展示模型名称、价格、折扣并可用详情、复制和对话入口，不互相遮挡。

## 边界

只改善模型广场展示与进入既有游乐场的体验；不改变收费、充值、汇率、渠道路由、数据库结构、认证规则或其他支付功能，不复刻参考截图的品牌与整页布局。
