# Outcome

模型广场以醒目的折扣标签展示模型优惠，并提供进入游乐场且选中该模型的入口。所有分组时取最低可用倍率，指定分组时展示该分组倍率；保留详情与复制。

# Scope

覆盖模型广场卡片和列表的折扣展示、对话入口及游乐场模型预选。以2026-10-27魔丸Token运营团队群需求及用户2026-10-28确认和补充为依据。最新三项要求：参考所附截图强化折扣标签、交换对话与复制图标、按选中分组展示折扣。

# Acceptance examples

- A1：卡片与列表在所有分组时按模型启用且访问者可用分组的最低有效倍率展示折扣，0.3、0.5、1显示“低至3折”；选定0.5分组时显示该组“5折”，切回所有分组恢复“低至3折”。不得使用无权限或模型未启用分组，不叠加充值或汇率。
- A2：当前展示倍率为0显示“免费”；0<倍率<1显示准确折数（所有分组用“低至”，指定分组用确切折数）；倍率>=1、缺失、无效或负数隐藏折扣。不得把缺失或极小正倍率显示为免费或0折，也不得把小于1的倍率舍入成10折。
- A3：仅游乐场支持的对话模型提供入口；卡片右上角现有复制与对话图标交换位置，视觉顺序为复制在前、对话在后，列表相邻操作保持一致。进入游乐场选中目标模型；详情和复制功能保留，不发送消息、不清空聊天。
- A4：模型预选等待有效选项加载；当前游乐场分组可用且支持目标模型时沿用，否则选账号可用且支持目标模型的最低倍率分组；空可用分组、目标不可用或加载失败明确提示，后续刷新不能静默改选另一模型冒充成功。
- A5：允许公开查看时访客使用公开分组倍率及相同筛选规则，入口提示“登录后体验”；登录后返回目标模型并刷新账号定价及权限。站点要求登录查看模型广场的设置保持有效。
- A6：折扣在卡片中为醒目的独立标签，仅参考描边、小标题及较大折数的两级层次；配色使用当前主题语义色，亮色浅底、暗色低亮度底色，折数和强调色契合主题主色并保持对比度，随主题切换更新，不固定金色，列表采用相容的紧凑样式；七语准确表达同一优惠（中文3折等价于其他语言减价70%），支持语言切换、明暗主题、键盘和可访问名称；窄屏不遮挡名称、价格、详情、复制及对话入口。

# Decisions

- 最新第3项替代原Q1的“分组筛选不改变折扣”。所有分组仍取权限交集最低倍率；指定分组只用当前组，不回退到其他更低组。
- 中文所有分组沿用“低至x折”，指定分组显示“x折”；倍率0为免费，无折扣时隐藏。
- 折扣标签的小标题和具体尺寸、颜色、布局由前端在现有设计系统内确定，参考截图层次，不复制整页。
- 现有pricing数据包含enable_groups、group_ratio及usable_group；价格本身已有按筛选组显示倍率的行为。
- 游乐场分组预选规则保持原确认：优先沿用游乐场当前可用组，否则选支持目标模型的最低倍率组；本次不新增把模型广场筛选组传入游乐场的行为。
- 访客只使用公开倍率，登录后重新检查账号权限和定价缓存；保留原登录可见设置。
- 使用当前main工作区的同一Native SDK change，保留已完成修复，由新的独立只读Verifier重新验收。

# Verification expectations

运行受影响组件与模型选择回归测试、类型检查、涉及文件lint及生产构建。浏览器核对分组切换、醒目标签、图标顺序、详情、复制、真实登录回跳及模型预选，并覆盖七语与窄屏。使用用户指定的Edge实例；不发送真实上游模型请求。独立Verifier验收全部条目。
