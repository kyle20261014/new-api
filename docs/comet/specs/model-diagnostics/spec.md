## 1. 入口与弹窗

在现有模型广场中增加“模型检测”入口，复用详情页与抽屉的共用模型信息，不另复制模型广场。整体参考 https://tk1688.com/market 的模型检测弹窗与用户两张附件，增加本平台所需的左侧授权分组栏。

弹窗包含模型名、分组、共享范围、通联/指纹/智力/绘画四项状态、技术报告入口；内容区显示分数、状态、来源、时间、耗时、可获得的真实 token 用量、过期提示及明细。状态标签用于查看结果；无报告时展示空状态和明确的开始按钮，不因切换标签、切换分组、打开报告或刷新页面而发送收费检测。

删除赞、踩、赞并入路由、禁用、固定此商家、加入路由；按用户最新决定删除绘画复测入口，使用“开始检测”发起一次生成。保留复制代码、下载、自由创作、提示词、创作素材、计分规则。绘画报告正文有独立滚动区域，底部操作可达；窄屏分组栏可折叠，不能造成按钮无法操作或横向溢出。保留键盘、焦点、读屏名称、可见错误及 loading 状态，沿用全站浅色/暗色主题与现有组件。

Scenario: 模型、分组切换与空结果
- 用户只能选择本人有权使用的模型和分组，服务端再次验证；无结果显示未检测，不伪造 0 分或通过。
- 切换模型/分组时报告、运行中任务和费用归属正确切换，迟到响应不能覆盖当前上下文。
- 查看报告、复制、下载、切页和刷新均不新建收费任务。

## 2. 共享、有效期与权限

标准检测报告按模型、授权分组、检测类型、完整参数和方法版本归档；同范围有权用户可查看，共享范围不等于全站无条件公开。自由创作报告仅本人可见。运行中任务可在同授权范围查看进度，但旁观者不能取消或操作他人任务。

报告保存真实来源和选路信息；对外不暴露用户身份、会话、Key、上游地址、内部渠道标识及私有分组。分组不等于固定渠道，一次检测不代表分组内全部渠道；界面明确“本次选路结果”。个人实际扣费仅发起者可见，公开使用量不能冒充其他用户的实际费用。

24 小时后保留并标记过期，不自动收费更新；已知配置或方法版本变化也标旧。无法保证立即识别上游内部换模，不把过期等同于失败。

Scenario: 报告授权与隐私
- 不具备当前模型/分组权限的读者不能通过报告 ID、列表或进度接口访问报告。
- 自由创作仅所有者可读，标准报告读取仍实时复核当前权限。
- 报告和日志公开响应不包含密钥、会话或内部渠道信息；费用明细不对其他用户公开。

## 3. 后端异步、计费与恢复

检测为后端持久化异步任务，关闭弹窗或前端断连不停止。前端重开后可读进度。状态至少包括排队、运行、完成、部分完成、失败、权限失效和待核查；执行状态与费用结清状态分开。

复用现有鉴权、模型/分组授权、请求校验、限流、正常中继选路及预扣、结算、退款；不通过管理员渠道测试接口，不复制额度算法，不伪装体验区路径或复用失效 Gin 上下文。每个未发送步骤重新验证发起者会话、用户及模型/分组权限；退出或撤权阻止后续发送，已在途调用仍按现有资金规则处理。

用最小 mowan_ 轮次/报告表及步骤表保存参数、版本、状态、结果、来源、用量和资金关联，复用既有系统任务 handler 作调度接点，不为每份报告创建相同唯一 ActiveKey 的系统任务。不增加全站四请求上限，不把全部用户检测整轮串行执行。

同一用户提交键重复提交返回原任务；同一共享范围已运行时返回原进度，不重复预扣。用户主动开始一次检测前提示按实际生成用量计费；绘画每次仅生成一份作品并完成一次本地判定，不因疑似、失败、过期或低分自动追加生成，不设置关联复测。预扣前持久化步骤和实际资金请求身份的关联；重启后已发送且结果不明的步骤进入待核查，不自动重发或假装退款。结算失败不能以 HTTP 成功标记已结清。

Scenario: 后台连续执行与幂等
- 创建后关闭弹窗并重开，能继续看到同一任务进度，重复点击不产生第二笔同步骤扣费。
- 注销/撤权后不发出新步骤；其他用户任务独立推进，不受某轮长任务整轮阻塞。
- 进程重启不自动重发结果不明的已发送步骤；报告内容成功与费用待核对可同时存在。

## 4. 通联测试

仅对支持对话接口的模型提供；非对话模型显示不适用，不发送对话请求。主动开始后通过正常中继发出一个简短请求；中继自身重试沿用原策略，不额外整轮重复。

报告展示真实成功/失败、可安全公开的错误、实际耗时及已获得用量；缺失用量显示未知。不可将供应商连通、模型能力、价格可用和身份真实性混为一谈。

Scenario: 通联适用性与结果
- 对话模型成功返回后显示成功；上游拒绝或超时显示对应失败，不伪造延迟或 token。
- 非对话模型禁用开始按钮，服务端同样拒绝不适用请求。

## 5. 指纹检测

使用已调查的 lm-detector Go SDK 固定提交 70159b7536a2ceb55c478c8c9472da81d3627e59 作为接入基线，保留 MIT 声明。固定可合法分发的参考数据及摘要、发布版本，从本地加载；不在用户检测中隐式下载、自动更新或发送数据到第三方检测服务。

通过 GenerateChallenges(3) 产生挑战，逐次经本站正常中继采样，再本地 Analyze；不直接使用自行发 HTTP 的 Detect。报告保存真实有效样本数、回答、挑战、参考库/检测器版本、参数及候选排名；不足三条有效回答为部分结果，不展示完整校准排名。实际来源不一致时显示无法判定，不自动追加付费采样。

置信度明确仅表示参考库内相似性，不是官方认证、模型真实身份或库外排除概率。参考库缺少候选、缺文件或校验失败时如实报无法判定，不伪造某个模型或成功结论。

Scenario: 指纹可解释性
- 三条同来源有效样本产生有版本、有依据的排名；不足或来源混合不冒充完整识别。
- 数据缺失/摘要错误不隐式联网补库，不输出伪置信度；报告可展开真实采样和方法局限。
